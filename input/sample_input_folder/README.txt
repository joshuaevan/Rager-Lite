Demo document collection for parser/tool testing
================================================

Included files:

PDF
- invoice_sample.pdf: single-page invoice-style PDF with a table and totals.
- quarterly_report_sample.pdf: multi-page report with headings, paragraphs, a table, and a vector bar chart.
- intake_form_sample.pdf: form-like layout with lines, boxes, and checkboxes.

TXT
- notes_utf8.txt: UTF-8 text with unicode, symbols, and a JSON snippet.
- app_log_crlf.txt: log-like text file using CRLF line endings.

CSV
- orders.csv: typical orders table (clean formatting).
- edge_cases.csv: commas, quotes, unicode, and multiline cells.
- timeseries.csv: 180 rows of time-series numeric data.

All content is synthetic.
